## What to build

`startSession` (`cmd/kota/main.go:1334-1379`) and `cmdCheck` (`main.go:1618-1641`) each run the Sandbox probes and then the Engine VM probes (`check.Run`, `probe.Failed`, `printResults`, `sess.engine.Probes(ds, sess.engine.ProbeTargets(sess.gateway))`). ```go
func check.Verify(ds *docker.Session, gw sandbox.Gateway, expect sandbox.Expect,
                  engine enginesession.State) (Results, error)
type Results struct{ Sandbox, Engine []probe.Result } // Engine nil when not run

- `Verify` runs the Sandbox probes, then the Engine VM probes when the Engine VM is on and got ready.
- `startSession` refuses when either suite has failures and prints the failures; `cmdCheck` prints every result with its timing, as today.

Deviations from the plan:

- `Verify(ds, gw, expect, engine check.Engine)` takes a small interface (`ProbeTargets`, `Probes`), which `*enginesession.Engine` satisfies, instead of `enginesession.State`. `enginesession` imports `check` to run its probes, so the State would make an import cycle. main.go's `probedEngine(sess, ready)` passes the VM only when it is on and ready, as a true nil otherwise.
- `Results` also has each suite's timing, for `check`'s output. On an error, `Verify` returns the results so far, so `check` still prints the Sandbox probes before it fails, as before. The "containment probes:" and "Engine VM probes:" error prefixes moved into `Verify`.
- run's printing and refusal moved into `verdict(w, results)`, which `TestVerdict` covers. When one suite fails, the refusal text is as before. When both fail: `refusing to start: N of M containment probes and N of M Engine VM probes failed (run 'kota check' for details)`.

`TestVerify` (no Docker) covers the Engine VM probes running after failed Sandbox probes, no Engine VM, and errors from either suite.

Verified: `go test ./...`, `go vet` (also with `GOOS=linux` and `-tags integration`), `gofmt`, and `go test -tags integration ./...` in every package. The 14 `TestEngineInShell` subtests ran against a real Engine VM and passed.
