## What to build

A Session's **Engine VM** state is three `session` fields in main.go: `engine` (`*enginesession.Engine`), `engineErr` (can't start, for `check`) and `engineOff` (`--no-engine`), set in `prepareSession` (`cmd/kota/main.go:787-805`) and read in `engineNote`, `printWarnings`, `printEngine`, `prepareSession` and `cmdCheck`. The agent-facing note about the Engine VM is `sandbox.EngineNote` (`internal/sandbox/spec.go:200`), in the compose-spec package.

`enginesession` returns one state value that is exactly one of:

- none: the project declares no **Engine images**
- off: declared, but the Session runs with `--no-engine`
- can't start: declared, with the error (`check` reports it; `run` and `shell` refuse before getting here)
- on: the `*Engine`

The value answers `Route()` (for `sandbox.Inputs`), `Note()` (the agent's note, today's `EngineNote` text, moved from `sandbox`) and `Warning()`. `session` holds it instead of the three fields. `sandbox` keeps `EngineEnv` and its values, which the compose spec sets.
