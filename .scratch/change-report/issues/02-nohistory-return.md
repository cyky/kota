## What to build

The rule for keeping a **No-history copy** (`CONTEXT.md`: uncommitted changes, refs not returned, or no **Returned branch** could be made) lives in main.go's `returnWork` (`cmd/kota/main.go:1127-1227`), with `bringBack` and `returned.report`. `nohistory` exposes the parts (`Uncommitted`, `Unreturned`, `Export`, `Import`, `BranchName`) and main.go assembles them. Only a Docker integration test reaches the keep decision, the step that can lose work.

```go
func Return(copy, original string, commits *changereport.Result, name string, start time.Time,
            run offlinegit.Runner, scratch string) Outcome
func (o Outcome) Report(w io.Writer)
```

- `Return` is today's `returnWork` and `bringBack`: export the copy's new commits to a bundle under `scratch`, import them into `original` as the Returned branch, decide whether to keep the copy, and delete it when nothing would be lost. It runs between `Finish` and cleanup, as today.
- `Outcome.Report` prints today's lines unchanged.
- The parts main.go assembles today become private.

Tests: table-driven unit tests of `Return` with a fake `Runner`, asserting kept or deleted and the reasons, for: no new commits, HEAD with no commit, rewritten history (`ErrRewritten`), failed export, failed import, uncommitted changes, refs not returned, unreadable commits, and a failed removal.
