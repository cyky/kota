## What to build

`cmdOffline` and `cmdPrep` (`cmd/kota/main.go:1087-1116`, `1753-1763`) each spell out the **Change report**'s order: snapshot watched files before Docker creates mount points, record refs, run, `commits.finish()` before cleanup, cleanup, diff the working tree after cleanup, print the commit report. The rules live in comments. `commitCheck`, `reportChanges`, `commitPaths` and `globalExcludes` (`main.go:1405-1570`) live in main.go, and the mask-to-warning mapping has no test of its own.

`changereport` takes the whole sequence:

```go
func Start(project string, layout mask.Layout, run offlinegit.Runner, opts Options) (*Check, error)
func (c *Check) Finish() *Result     // once containers are gone, before cleanup
func (r *Result) Report(w io.Writer) // after cleanup
type Options struct{ Copy bool; ConfigHome string }
```

- `Start` snapshots the watched files and reads the refs. An unreadable snapshot is an error, unreadable refs a warning printed by `Report`, as today.
- `Finish` reads the refs and history. `Report` diffs the working tree and prints every line: changed watched files, history, and commit warnings.
- `commitPaths` and `globalExcludes` move in; `ConfigHome` replaces the environment lookup, for tests. `HistoryLines`, `WarningLines`, `Diff`, `CheckCommits` and the other parts main.go assembles today become private.
- `Copy` is a No-history copy: the history heading says "in the copy", and there's no working-tree snapshot or diff. Behaviour change: today the snapshot is taken and discarded.
- `Result` exposes the refs before and after, for `nohistory.Return` (issue 02).
