## What to build

The usage text stops copying agent facts by hand (`cmd/kota/main.go:103-104`, `123-138`):

- `agent.Default` and `agent.Names()` replace `defaultAgent` and the hard-coded names in the `--agent` line and the unknown-agent error.
- `agent.OverrideHelp()` returns the override paragraph of the usage text: each override file under `$XDG_CONFIG_HOME/kota/`, what it is merged over, and its allowed keys (or "rebinds any of pi's actions" for an any-key policy), built from the policies. opencode.json's pointer to cli.json for keybinds and theme stays.
- The README and `docs/agent-setup.md` keep their own prose. A test checks that every allowed key of every override policy appears in `docs/agent-setup.md`, so a key added to a policy can't be left out of the docs silently.

The wording of the generated text may differ from today's, but it says the same things.
